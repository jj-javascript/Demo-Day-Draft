Project Overview
Compiler is a full-stack web application where users can send content from their social media applications to view in one media feed entirely curated by them.
<img width="1721" height="954" alt="Compilr" src="https://github.com/user-attachments/assets/60be3eb4-2245-44b8-8b31-4a3b9d521eb2" />

Features
Add items from any link and parse information.
View logged items in user-friendly display and use it to access links.
Organize items in custom feeds.
Update/delete informaton within items.

Installation
Clone the repository:
git clone https://github.com/yourusername/Demo-Day-Draft.git
Navigate to the project directory:
cd Demo-Day-Draft
Install Dependencies:
npm install
Start the server:
npm run dev
Open your browser and go to:
http://localhost:6001
Usage
Log in or create an account.
Add a new submission by entering a link of your choice.
Submit the item and watch as it is added to the feed.
Use custom feeds to add additional items.
Click the 🗑️ trash icon to delete items.

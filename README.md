# Compilr

A full-stack Node.js and Express web application that allows users to compile their content they would like to see later into one sleek social feed.

## Project Overview

Compiler is a full-stack web application where users can send content from their social media applications to view in one media feed entirely curated by them.
<img width="1721" height="954" alt="Compilr" src="https://github.com/user-attachments/assets/60be3eb4-2245-44b8-8b31-4a3b9d521eb2" />

## Features

-Add items from any link and parse information.
-View logged items in user-friendly display and use it to access links.
-Organize items in custom feeds.
-Update/delete informaton within items.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/Compilr-Draft.git
````

2. Navigate to the project directory:

```bash
cd demo-day-draft
```

3. Install Dependencies:
```bash
npm install
```
4. Start the server:
```bash
npm run dev
```
5. Open your browser and go to:
```bash
http://localhost:6001
```

## Usage

1. Add a new submission by entering a link of your choice.
2. Submit the item and watch as it is added to the feed.
3. Use custom feeds to sort items to the feed of your choice.
4. Click the 🗑️ trash icon to delete items.
